## Known gaps (documented, not gated)

| Case | What happens | Note |
| --- | --- | --- |
| `evasion-split-across-fields` | secret crossed the wire | No detector joins key fragments split across different parts of the payload; the model can reassemble them upstream. |

## Methodology

- Every case drives the full production pipeline over real loopback HTTP —
  smuggling checks, rate limiting, field extraction, the DLP engine, the
  obfuscation probe, forwarding, and response-side inspection — using the
  same router `open-guardian start` serves.
- The mock upstream records the exact bytes that crossed the wire; a
  **leak** means the literal secret appeared in what the upstream received
  (request cases) or what the client received (response cases).
- Evasion cases (encoding, entities, homoglyphs, zero-width characters)
  must be rejected fail-closed, not forwarded.
- `restore` cases prove the differentiator: the upstream only ever sees
  placeholders, while the local client gets the original value back.
- Benign cases must arrive semantically unchanged (JSON-semantic compare,

  since the proxy legitimately re-serializes bodies).
